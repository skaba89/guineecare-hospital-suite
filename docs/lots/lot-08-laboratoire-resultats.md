# Lot 08 — Laboratoire et résultats

## Objectif

Digitaliser le circuit laboratoire : demande, prélèvement, réception, analyse, saisie de résultat, validation et diffusion dans le dossier patient.

## Modules inclus

- Catalogue des examens.
- Demandes laboratoire.
- Prélèvements.
- Étiquettes échantillons.
- Réception laboratoire.
- Saisie des résultats.
- Validation biologique.
- Résultats critiques.
- Compte rendu PDF.
- Statistiques laboratoire.

## Acteurs

- Médecin demandeur.
- Infirmier préleveur.
- Technicien laboratoire.
- Biologiste.
- Responsable laboratoire.

## Règles métier

- Un résultat brouillon ne doit pas être diffusé comme résultat final.
- Une validation biologique est requise pour la diffusion officielle.
- Un échantillon rejeté doit avoir un motif.
- Un résultat critique doit déclencher une alerte.

## Critères d'acceptation

- Créer une demande d'examen.
- Enregistrer un prélèvement.
- Réceptionner un échantillon.
- Saisir un résultat.
- Valider un résultat.
- Générer un compte rendu.
