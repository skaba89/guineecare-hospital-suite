# Lot 12 — Personnel et planning

## Objectif

Organiser les équipes de l'hôpital avec des fiches agents, des affectations, des horaires et des gardes.

## Modules inclus

- Fiches agents.
- Services d'affectation.
- Fonctions.
- Planning.
- Gardes.
- Présences.
- Absences.
- Remplacements.

## Acteurs

- Direction.
- Responsable du personnel.
- Chef de service.
- Cadre de santé.
- Agent hospitalier.

## Règles métier

- Un agent doit être rattaché à un établissement.
- Un agent ne doit pas être planifié deux fois sur le même créneau.
- Les remplacements doivent être conservés dans l'historique.

## Critères d'acceptation

- Créer une fiche agent.
- Affecter un agent à un service.
- Créer un planning.
- Gérer une garde.
- Gérer une absence.
- Voir les agents disponibles.
