# Lot 03 — Dossier Patient Informatisé clinique

## Objectif

Mettre en place le dossier médical numérique du patient, consultable par les professionnels autorisés.

## Modules inclus

- Synthèse patient.
- Antécédents.
- Allergies.
- Constantes.
- Observations médicales.
- Diagnostics.
- Prescriptions.
- Documents cliniques.
- Timeline médicale.

## Acteurs

- Médecin.
- Infirmier.
- Sage-femme.
- Urgentiste.
- Pharmacien selon droits.
- Biologiste selon droits.

## Règles métier

- Le DPI est consultable uniquement par les profils autorisés.
- Toute consultation sensible doit être auditée.
- Une note signée ne doit pas être modifiée directement.
- Les résultats laboratoire et imagerie validés doivent remonter dans le DPI.

## Critères d’acceptation

- Voir la synthèse patient.
- Ajouter une note clinique.
- Ajouter des constantes.
- Ajouter un diagnostic.
- Voir la timeline.
- Générer un document clinique.
