# Lot 02 — Patient, admission, rendez-vous et file d’attente

## Objectif

Digitaliser l’identification du patient et organiser le parcours d’entrée dans l’hôpital.

## Modules inclus

- Création patient.
- Recherche patient.
- Identité administrative.
- Admission consultation.
- Admission urgence.
- Admission hospitalisation.
- Rendez-vous.
- File d’attente.
- Orientation service.

## Acteurs

- Agent accueil.
- Agent admission.
- Médecin.
- Infirmier.
- Caissier.
- Responsable de service.

## Règles métier

- Un patient doit avoir un identifiant unique.
- Un doublon patient doit pouvoir être détecté.
- Une admission doit être rattachée à un établissement et à un service.
- La file d’attente doit être visible par service.

## Critères d’acceptation

- Créer un patient.
- Rechercher un patient.
- Créer une admission.
- Planifier un rendez-vous.
- Voir la file d’attente.
- Orienter le patient vers le bon service.
