# Lot 14 — Reporting national et pilotage ministériel

## Objectif

Consolider les données hospitalières pour produire les indicateurs sanitaires, les rapports et les tableaux de bord de pilotage.

## Modules inclus

- Référentiel établissements.
- Référentiel indicateurs.
- Calcul indicateurs.
- Rapports périodiques.
- Contrôle qualité données.
- Dashboard hôpital.
- Dashboard régional.
- Dashboard national.
- Exports.
- Interopérabilité future.
- Alertes sanitaires.

## Acteurs

- Statisticien hospitalier.
- Direction hôpital.
- Direction régionale.
- Ministère.
- Administrateur SI.
- Data analyst.

## Règles métier

- Les données nationales doivent être agrégées par défaut.
- Les rapports validés doivent être verrouillés.
- Toute correction après validation doit être justifiée.
- Les exports doivent être tracés.

## Critères d'acceptation

- Définir un indicateur.
- Calculer les valeurs.
- Lancer les contrôles qualité.
- Valider un rapport.
- Voir les dashboards.
- Exporter les données autorisées.
