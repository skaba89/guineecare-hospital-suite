# Lot 11 — Bloc opératoire

## Objectif

Gérer le parcours opératoire depuis la demande d'intervention jusqu'au retour du patient en service.

## Modules inclus

- Demande d'intervention.
- Programme opératoire.
- Salles opératoires.
- Équipe opératoire.
- Évaluation préopératoire.
- Checklist de salle.
- Intervention.
- Compte rendu opératoire.
- Salle de réveil.
- Consommables.
- Stérilisation.

## Acteurs

- Chirurgien.
- Anesthésiste.
- Infirmier de bloc.
- Instrumentiste.
- Agent de stérilisation.
- Major bloc.

## Règles métier

- Une intervention doit être rattachée à un patient.
- Le programme opératoire doit gérer les salles et les horaires.
- La checklist doit être complétée ou justifiée.
- Le compte rendu signé doit être visible dans le dossier patient.

## Critères d'acceptation

- Créer une demande.
- Programmer une salle.
- Démarrer une intervention.
- Renseigner l'équipe.
- Créer le compte rendu.
- Suivre les consommables.
