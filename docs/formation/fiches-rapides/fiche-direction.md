## Actions essentielles

### 1. Consulter le tableau de bord direction
1. Après connexion, le tableau de bord direction affiche les KPI globaux : fréquentation, finances, qualité, ressources.
2. Vérifier les alertes (incidents graves, retards de paiement, surcharge service).
3. Cliquer sur un KPI pour ouvrir la vue détaillée.

> **Astuce** : consulter le tableau de bord chaque matin avant 9h pour anticiper la journée.

### 2. Consulter les indicateurs de fréquentation
1. Menu **Reporting** → **Fréquentation**.
2. Vérifier : nouveaux patients, admissions, urgences, lits occupés, taux d'occupation.
3. Comparer à la période précédente (veille, semaine précédente, mois précédent).

> **Astuce** : surveiller le taux d'occupation lits — un taux > 90 % pendant 3 jours doit déclencher une réunion de régulation.

### 3. Consulter les indicateurs financiers
1. Menu **Reporting** → **Finances**.
2. Vérifier : encaissements du jour, impayés, évolution mensuelle, EV par service.
3. Repérer les services en déficit ou les recettes anormalement basses.

### 4. Consulter les indicateurs qualité
1. Menu **Qualité** → **Indicateurs**.
2. Vérifier : incidents déclarés, satisfaction patient, conformité protocoles, RMM réalisées.
3. Cliquer sur un indicateur pour voir le détail et l'évolution mensuelle.

### 5. Filtrer les indicateurs par période
1. Dans n'importe quelle vue d'indicateur → sélecteur de période en haut.
2. Choisir : jour, semaine, mois, trimestre, année, ou plage personnalisée.
3. Les graphiques et tableaux se mettent à jour.

> **Astuce** : pour le COM mensuel, sélectionner le mois écoulé et exporter le rapport (action 8).

### 6. Comparer les indicateurs entre services
1. Menu **Reporting** → **Comparaison services**.
2. Choisir l'indicateur (fréquentation, finances, qualité) et la période.
3. Le tableau compare tous les services côte à côte, avec tri par colonne.

> **Attention** : les comparaisons brutes peuvent être trompeuses — pondérer par l'activité (lit, consultation) pour une analyse juste.

### 7. Consulter le journal d'audit global
1. Menu **Audit** → **Journal global**.
2. La liste affiche les actions sensibles (modifications, suppressions, accès DPI).
3. Cliquer sur une ligne pour voir le détail (utilisateur, cible, horodatage, avant/après).

> **Attention** : l'accès au journal d'audit est lui-même tracé — ne pas en abuser.

### 8. Exporter un rapport mensuel
1. Menu **Reporting** → **Rapports** → **Nouveau rapport mensuel**.
2. Sélectionner le mois, le périmètre (établissement, service) et le format (PDF ou CSV).
3. **Générer** → le rapport est téléchargé. Stocker dans le dossier de la direction.

> **Astuce** : archiver les rapports mensuels par année pour faciliter les comparaisons annuelles et les audits.

### 9. Consulter les feedbacks utilisateurs
1. Menu **Feedback** → **Liste des retours**.
2. Filtrer par catégorie (bug, suggestion, question, praise) et par statut (nouveau, en cours, résolu).
3. Cliquer sur un feedback pour voir le détail et l'historique de traitement.

### 10. Trier et résoudre un feedback
1. Ouvrir un feedback → changer le statut (en cours, résolu, wontfix).
2. Saisir une réponse dans le champ **Réponse** (visible par l'utilisateur).
3. **Enregistrer**. L'utilisateur reçoit une notification dans l'application.

> **Astuce** : répondre même aux feedbacks wontfix — l'utilisateur doit comprendre la décision pour rester engagé.

## Que faire en cas de problème ?

| Problème | Solution |
|----------|----------|
| Page blanche | F5 (rafraîchir) |
| Données non enregistrées | Vérifier connexion, ne pas fermer la page |
| Compte bloqué | Attendre 15 min ou appeler admin (poste 4012) |
| Application inaccessible | Vérifier https://, appeler hotline niveau 1 |
| Indicateur aberrant | Vérifier la source, alerter l'admin si incohérent |
