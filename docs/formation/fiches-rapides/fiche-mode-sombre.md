# Fiche rapide — Mode sombre 🌙

> Public : tous les utilisateurs
> Module(s) : toutes les pages
> Version : v2.9.2 — juillet 2026
> À imprimer recto-verso et à garder à portée de main au poste de travail.

---

## Activation du mode sombre

| Étape | Action |
|-------|--------|
| 1 | Se connecter à GuinéeCare |
| 2 | Dans la barre supérieure (topbar), repérer le bouton **🌙** |
| 3 | Cliquer dessus — l'interface passe immédiatement en sombre |
| 4 | Pour revenir en mode clair, cliquer sur **☀️** |

## Comportement

- ✅ **Persistance** : la préférence est mémorisée (localStorage) — vous restez en mode sombre après déconnexion
- ✅ **Système** : au premier chargement, suit votre préférence système (`prefers-color-scheme`)
- ✅ **Navigation** : le thème est conservé sur toutes les pages

## Pourquoi utiliser le mode sombre ?

- 👁️ **Confort oculaire** : idéal pour les gardes de nuit, salles de radiologie, environnements peu éclairés
- 🔋 **Économie d'énergie** : jusqu'à 40 % d'économie sur les écrans OLED/AMOLED
- 🎯 **Concentration** : moins de fatigue visuelle après plusieurs heures d'usage

## Problèmes fréquents

| Problème | Solution |
|----------|----------|
| Le mode sombre ne s'applique pas | Vider le cache : Ctrl+Shift+R (ou Cmd+Shift+R) |
| Le bouton 🌙 n'apparaît pas | Vérifier que vous êtes sur la version v2.9.2+ |
| Certains textes illisibles | Contacter tech@guineecare.gn (capture d'écran souhaitée) |
