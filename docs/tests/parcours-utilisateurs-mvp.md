# Parcours utilisateurs MVP

## Parcours 1 — Admission consultation

1. L'agent recherche le patient.
2. Si le patient n'existe pas, il crée une fiche.
3. Il crée une admission consultation.
4. Le patient apparaît dans la file du service.
5. Le médecin ouvre le dossier.
6. Le médecin saisit l'observation.
7. La consultation est clôturée.

## Parcours 2 — Passage urgence

1. L'agent crée un passage urgence.
2. L'infirmier réalise le triage.
3. Le niveau de priorité est affecté.
4. Le médecin voit le patient dans la file urgence.
5. Le médecin saisit l'observation et l'orientation.
6. Le patient sort ou est orienté vers hospitalisation.

## Parcours 3 — Hospitalisation

1. Le médecin demande une hospitalisation.
2. L'agent affecte un lit disponible.
3. Le séjour est ouvert.
4. Les soins et observations sont ajoutés.
5. Le patient change éventuellement de lit ou de service.
6. Le médecin prépare la sortie.
7. Le séjour est clôturé.

## Parcours 4 — Pharmacie

1. Le pharmacien crée un produit.
2. Il ajoute une entrée en stock.
3. Le service demande une sortie.
4. Le pharmacien valide la sortie.
5. Le stock est mis à jour.
6. Une alerte apparaît si le seuil minimum est atteint.

## Parcours 5 — Laboratoire

1. Le médecin crée une demande laboratoire.
2. Le laboratoire reçoit la demande.
3. L'échantillon est enregistré.
4. Le résultat est saisi.
5. Le résultat est validé.
6. Le médecin voit le résultat dans le dossier patient.

## Parcours 6 — Facturation

1. Une facture est créée pour le patient.
2. Les lignes sont ajoutées.
3. Le caissier encaisse le paiement.
4. Le reçu est généré.
5. La facture passe en statut payé ou partiellement payé.
6. La caisse est clôturée en fin de journée.

## Parcours 7 — Reporting direction

1. La direction ouvre le dashboard hôpital.
2. Les indicateurs du jour sont visibles.
3. Le statisticien lance un rapport mensuel.
4. Les anomalies sont contrôlées.
5. Le rapport est exporté.
