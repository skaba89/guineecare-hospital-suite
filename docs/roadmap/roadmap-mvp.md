# Roadmap MVP — GuinéeCare Hospital Suite

Construire une première version exploitable dans un hôpital pilote, puis préparer l'extension régionale et nationale.

- Ateliers métier.
- Audit terrain.
- Validation du cahier des charges.
- Priorisation MVP.
- Architecture cible.
- Plan de conduite du changement.

- Établissements.
- Services.
- Référentiels.
- Audit.

## Phase 2 — Parcours patient

- Admission.
- Rendez-vous.
- File d'attente.
- DPI de base.

## Phase 3 — Modules cliniques prioritaires
