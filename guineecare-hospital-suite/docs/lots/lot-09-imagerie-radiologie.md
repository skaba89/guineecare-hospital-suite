# Lot 09 — Imagerie médicale et radiologie

## Objectif

Gérer les demandes d'imagerie, la planification, la réalisation des examens, les comptes rendus et la diffusion dans le dossier patient.

## Modules inclus

- Catalogue imagerie.
- Demandes d'examens.
- Planning radiologie.
- File radiologie.
- Réalisation examen.
- Compte rendu.
- Signature.
- Diffusion DPI.
- Préparation PACS et DICOM.

## Acteurs

- Médecin demandeur.
- Agent radiologie.
- Manipulateur radio.
- Radiologue.
- Direction médicale.

## Règles métier

- Une demande doit avoir une indication clinique.
- Un compte rendu signé est diffusé dans le DPI.
- Une correction doit conserver l'historique.
- Les examens urgents sont priorisés.

## Critères d'acceptation

- Créer une demande.
- Planifier un examen.
- Marquer l'examen réalisé.
- Rédiger un compte rendu.
- Signer le compte rendu.
- Voir le résultat dans le DPI.
