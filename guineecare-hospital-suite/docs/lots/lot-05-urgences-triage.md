# Lot 05 — Urgences et triage

## Objectif

Organiser l'accueil des patients non programmés, le triage, la priorisation et l'orientation rapide vers le bon circuit de prise en charge.

## Modules inclus

- Admission urgence.
- Triage.
- Priorité couleur.
- File urgence.
- Box ou salle.
- Actes immédiats.
- Observations.
- Orientation.
- Tableau temps réel.

## Acteurs

- Agent accueil.
- Infirmier triage.
- Médecin urgentiste.
- Brancardier.
- Service cible.

## Règles métier

- Les cas prioritaires remontent en haut de file.
- Le triage est horodaté.
- Toute modification de priorité est justifiée.
- L'orientation finale est conservée dans la timeline.

## Critères d'acceptation

- Créer un passage urgence.
- Réaliser le triage.
- Affecter une priorité.
- Affecter un box.
- Orienter vers sortie ou hospitalisation.
- Voir le dashboard urgence.
