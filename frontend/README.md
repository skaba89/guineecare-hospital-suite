# Frontend — GuinéeCare Hospital Suite

Interface web de la plateforme hospitalière.

## Stack cible

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- React Hook Form

## Pages MVP prévues

- Connexion
- Dashboard
- Patients
- Admissions
- DPI
- Urgences
- Hospitalisation
- Pharmacie
- Laboratoire
- Facturation
- Reporting

## Lancement local prévu

```bash
cd frontend
npm install
npm run dev
```
