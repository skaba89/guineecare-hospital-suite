# Structure frontend MVP

## Objectif

Définir la structure cible de l'interface web GuinéeCare.

## Pages MVP

- Login
- Dashboard
- Patients
- Admissions
- Dossier patient
- Urgences
- Hospitalisation
- Pharmacie
- Laboratoire
- Facturation
- Reporting

## Composants communs

- Layout principal
- Sidebar
- Header
- Card KPI
- Tableau de données
- Formulaire patient
- Badge statut
- Modal confirmation
- Toast notification

## Services API

- authService
- patientService
- admissionService
- clinicalService
- emergencyService
- hospitalizationService
- pharmacyService
- laboratoryService
- billingService
- reportingService

## Priorité UX

L'interface doit être simple, rapide, lisible et adaptée aux utilisateurs hospitaliers.
